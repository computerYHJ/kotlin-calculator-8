# 기능 구현 목록

### 오류체크
1. 입력 문자열을 체크하여 숫자가 하나도 없으면 오류를 발생
2. split을 통해 list 생성 후, list의 요소 하나하나 Integer.parseInt 시
   NumberFormatException 발생 시 오류 발생
3. 만약 list의 요소에 음수가 있다면 마찬가지로 NumberFormatException 발생
4. 오류는 IllegalArgumentException으로 통일

### 커스텀 구분자 체크 부분
1. 정규식을 활용하여 //?\n 안의 ?를 확인하는 과정
2. 만약 //?\n의 형식이 아니라면 if문을 통해 바로 탈출
3. 커스텀 부분자의 형식이 잘못되더라도 오류체크 부분의 2번을 통해
   NumberFormatException 발생하여 오류 발생

### 기존 구분자 체크 부분
1. 기존 구분자는 list에 넣어두어 기능 구현의 최적화에 사용

### 계산
1. 오류체크 부분의 2번이 정상적으로 진행된다면 answer 변수에 하나하나 저장
2. 만약 숫자로 변환이 안된다면 바로 오류체크의 2번으로 넘어감
3. 음수가 존재한다면 오류체크의 3번으로 넘어감

### 오류 발생 부분
1. 숫자가 하나라도 입력되지 않는다면 '숫자가 포함된 문자열을 입력해주세요' 라는 오류구문 삽입
2. 커스텀 부분자나 기본 구분자가 없고, 음수가 입력된다면 '잘못된 입력입니다' 라는 오류구문 삽입
